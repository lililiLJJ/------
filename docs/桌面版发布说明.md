# 桌面版发布说明

## 目标

桌面版用于让客户脱离 WPS 加载项使用工程资料制作软件。

当前切片保留既有本地生成服务和 Web 前端，新增桌面启动器：

- 自动启动 `GeneratorService`
- 打开 `WebClient/dist/index.html`
- 不安装 WPS 加载项
- 不写入 `%APPDATA%/kingsoft/wps/jsaddons`
- 生成后的 `.xlsx` 仍由系统默认表格软件打开

## 组包命令

在项目根目录执行：

```powershell
$OutputEncoding = [Console]::OutputEncoding = [Text.UTF8Encoding]::new($false)
powershell -NoProfile -ExecutionPolicy Bypass -File "tools/BuildDesktopPackage.ps1"
```

指定版本号：

```powershell
$OutputEncoding = [Console]::OutputEncoding = [Text.UTF8Encoding]::new($false)
powershell -NoProfile -ExecutionPolicy Bypass -File "tools/BuildDesktopPackage.ps1" -Version "v1.0.0-desktop"
```

## 输出目录

脚本会生成：

```text
publish/ReleasePackage/EngineeringDocs-Desktop-版本号/
├── Client/
└── Issuer/
```

## Client 目录

客户使用 `Client/` 目录：

```text
Client/
├── EngineeringDocsDesktop.exe
├── 1-Start-Desktop.cmd
├── 2-Start-Service-Only.cmd
├── GeneratorService/
├── WebClient/
├── Templates/
├── KnowledgeBase/
├── Keys/
├── Export/
├── Logs/
├── Projects/
├── Docs/
└── README.md
```

客户双击：

```text
EngineeringDocsDesktop.exe
```

或：

```text
1-Start-Desktop.cmd
```

启动器会先检查：

```text
http://127.0.0.1:5188/api/health
```

如果服务未启动，会自动启动：

```text
GeneratorService/GeneratorService.exe
```

服务就绪后打开：

```text
WebClient/dist/index.html
```

## Issuer 目录

`Issuer/` 仍然只给授权方自己保留，用于放置发码工具和私钥。

不要把私钥发给客户。

## 当前边界

当前桌面版已经脱离 WPS 加载项安装与 Ribbon 入口，但仍使用系统默认浏览器承载前端页面。

下一步如需更像传统桌面软件，可新增 WebView2 桌面壳，把 `WebClient/dist/index.html` 内嵌到窗口中。这样需要引入 `Microsoft.Web.WebView2` 包，当前离线环境未发现该包缓存，因此本切片先采用无外部依赖的桌面启动器方案。
