# 规范层级树资料表删除与批量删除执行改动方案

## 1. 目标

本次改动聚焦“模板节点不删除，只删除模板下已生成资料表”的完整删除链路，覆盖以下同步要求：

- 左侧规范层级树立即刷新
- 当前预览/选中状态同步切换
- 右侧预览区同步清空或切换到同模板下其他资料表
- 工程数据记录同步删除
- `GeneratedForms` 下对应 `.xlsx` 文件同步删除
- 顶部批量操作支持模板节点全选、半选、取消

## 3. 后端执行方案

### 3.1 树节点语义统一

- 模板节点统一为 `template`
- 已生成资料表节点统一为 `document`
- 保留对旧 `generated_form` 数据的兼容读取，但对前端输出统一映射为 `document`

### 3.2 节点与资料表标识

- 模板操作统一使用 `templateNodeId`
- 资料表操作统一使用 `documentId`
- 树节点 DTO 补充以下字段：
  - `templateNodeId`
  - `documentId`
  - `templateName`
  - `formName`
  - `createdAt`
  - `updatedAt`

### 3.3 删除接口

新增并启用以下接口：

- `GET /api/project-documents/{documentId}`
- `POST /api/project-documents/{documentId}/open`
- `POST /api/project-documents/{documentId}/backups`
- `DELETE /api/project-documents/{documentId}`
- `POST /api/project-documents/batch-delete`

兼容说明：

- 旧 `/api/generated-forms/*` 路由仍保留兼容
- 前端新的删除/打开链路改走 `/api/project-documents/*`

### 3.4 删除处理顺序

单删与批删共用同一条删除管线：

1. 校验 `documentId` 是否属于当前工程/当前单位工程
2. 读取资料表记录与生成文件路径
3. 尝试删除实际 `.xlsx` 文件
4. 文件删除成功后删除工程记录
5. 返回删除结果、失败原因与父模板信息

失败策略：

- 某个文件删除失败时，不删除该条工程记录
- 批量删除允许部分成功，失败项进入 `failedItems`

## 4. 前端执行方案

### 4.1 普通模式

- 默认不显示复选框
- 已生成资料表节点悬停显示行内“删除”按钮
- 右键菜单支持：
  - 打开
  - 删除表格
  - 定位文件

### 4.2 批量模式

- 新增顶部入口：`批量管理`
- 进入后显示：
  - 复选框
  - 已选数量
  - 批量删除按钮
  - 取消按钮
- 退出批量模式时清空勾选状态

### 4.3 模板节点勾选规则

- 模板节点勾选会同步勾选其下全部已生成资料表
- 模板节点取消会同步取消其下全部已生成资料表
- 模板节点支持三态：
  - 全选
  - 半选
  - 未选

### 4.4 删除前 WPS 处理

- 删除前先检查目标文件是否已在 WPS 中打开
- 未打开：直接删除
- 已打开且已保存：自动关闭后删除
- 已打开且未保存：提示用户“保存并关闭 / 不保存关闭 / 取消删除”
- 批量删除逐个执行预检查，单项失败不影响其他项

### 4.5 删除后联动

- 删除成功后重新加载模板树
- 当前预览资料表被删时：
  - 优先切到同模板下下一张剩余资料表
  - 若无剩余资料表，回到模板节点详情页
- 同步刷新汇总树
- 批量选择状态按 `documentId` 维护，刷新后自动剔除已不存在的资料表

## 5. 安全边界

本次功能明确不处理以下对象：

- 模板源文件
- 模板适配配置
- 字段映射配置
- 模板目录/模板节点本身

删除动作仅作用于：

- 工程生成资料表记录
- `GeneratedForms` 下对应生成文件
