# 发布包说明

## 1. 目标

把当前仓库整理成两套可直接交付的目录：

- `Client`：发给客户安装和使用
- `Issuer`：授权方自己保留，用于生成激活码

这样可以把“客户运行文件”和“发码工具/私钥”彻底分开，减少误发风险。

## 2. 组包命令

在项目根目录执行：

```powershell
$OutputEncoding = [Console]::OutputEncoding = [Text.UTF8Encoding]::new($false)
powershell -ExecutionPolicy Bypass -File ".\tools\BuildReleasePackage.ps1"
```

如果需要指定版本号：

```powershell
$OutputEncoding = [Console]::OutputEncoding = [Text.UTF8Encoding]::new($false)
powershell -ExecutionPolicy Bypass -File ".\tools\BuildReleasePackage.ps1" -Version "v1.1.0-license-tool-release"
```

## 3. 输出目录

脚本会生成：

```text
publish/ReleasePackage/EngineeringDocs-WPS-版本号/
├── Client/
└── Issuer/
```

## 4. Client 目录

```text
Client/
├── 1-Install-Client.cmd
├── 2-Uninstall-Client.cmd
├── 1-Start-GeneratorService.cmd
├── Install-Client.ps1
├── Uninstall-Client.ps1
├── Start-GeneratorService-Silent.ps1
├── config.example.json
├── GeneratorService/
├── WpsAddin/
├── Templates/
├── KnowledgeBase/
├── Keys/
├── Export/
├── Logs/
├── Docs/
└── README.md
```

作用：

- 一键安装 WPS 加载项
- 注册本地生成服务开机静默启动
- 提供 WPS 加载项页面文件
- 提供模板、知识库、公钥
- 提供日志目录和导出目录

客户首次使用时双击：

```text
1-Install-Client.cmd
```

安装脚本会完成：

- 把 `WpsAddin/` 复制到 `%APPDATA%/kingsoft/wps/jsaddons/engineering-docs-wps-addin_0.1.0`
- 写入 `%APPDATA%/kingsoft/wps/jsaddons/publish.xml`
- 注册当前用户计划任务 `EngineeringDocsGeneratorService`
- 立即静默启动 `GeneratorService.exe`
- 如果不存在 `config.json`，从 `config.example.json` 复制一份

后续客户不需要再从终端启动服务，直接打开 WPS 表格即可看到顶部“工程资料”加载项。

如果 WPS 安装前已经打开，需要完全退出 WPS 后重新打开。

## 5. Issuer 目录

```text
Issuer/
├── 1-Generate-RSA-Keys.cmd
├── 2-Create-Activation-Code.cmd
├── LicenseTool/
├── Keys/
├── Docs/
└── README.md
```

作用：

- 生成 RSA 密钥对
- 交互式生成激活码
- 保存私钥
- 保留客户机器码收集模板和说明文档

## 6. 安全要求

- `Issuer/Keys/license-private.pem` 绝不能发给客户
- 客户只需要 `Client/Keys/license-public.pem`
- 发给客户的是工具最终输出的 `激活码 Base64`

## 7. 推荐交付方式

建议把 `Client/` 和 `Issuer/` 分开压缩：

- `Client.zip` 发给客户
- `Issuer.zip` 自己保存

这样最不容易操作失误。
