# 实施说明

## 当前 MVP 的边界

本版本先跑通完整链路：控制面板输入、调用本地服务、读取模板、查询 SQLite 知识库、替换占位符、生成 Excel 文件。

## 为什么先做本地服务

WPS JS 插件适合做界面，不适合直接处理大量 Excel 文件、授权、日志和数据库。核心逻辑放到本地 C# 服务后，后续可以独立测试、独立发布，也方便做商业授权。

## 为什么模板永不修改

模板是格式资产，生成时只复制模板并修改副本。这样可以保证每次生成都从干净模板开始，避免模板被污染。

## 为什么规范数据必须来自 SQLite

工程资料里的主控项目、一般项目、允许偏差、检查方法属于严肃数据，不能由 AI 编写。程序遇到知识库缺失时会直接失败并记录日志。
