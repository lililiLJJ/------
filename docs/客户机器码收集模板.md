# 客户机器码收集模板

你可以把下面这段文字直接发给客户：

---

你好，请按下面步骤把机器码发给我：

1. 打开 WPS 表格
2. 打开右侧“工程资料”插件
3. 点击“软件激活”
4. 点击“复制机器码”
5. 把复制出来的 `机器码 Hash` 直接发给我

注意：

- 只需要发 `机器码 Hash`
- 不需要发截图也可以
- 如果你已经有激活码，不要重复点击“激活”

你发给我的内容示例：

```text
5311953D72077E224375E0B342E898EA30F50001B8A9B4FF8C12E53B26066464
```

---

你自己发码时建议流程：

1. 先双击 `tools/LicenseTool/2-交互式生成激活码.cmd`
2. 按提示输入客户机器码、授权类型、到期日期
3. 复制最终输出的 `激活码 Base64`
4. 把这串激活码发回客户
